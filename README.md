# slope

![test](https://github.com/kuroiwarikuto/slope/actions/workflows/test.yml/badge.svg)

標準入力から受け取った数値列の変化率（傾き）を計算し、標準出力へ返すコマンドです。

## 機能

- 1行につき1つの数値（整数・小数）を標準入力から読み込み、連続する2つの値の差を出力します。
- `-d`（または `--delta`）オプションでデータ間の刻み幅を指定すると、変化率を計算します。
- パイプでつなぐことで、2階差分（加速度など）の計算にも対応できます。

## インストール方法

```bash
$ git clone https://github.com/kuroiwarikuto/slope.git
$ cd slope
```

## 使い方

### 基本的な実行例

数値を改行区切りで標準入力へ渡します。

```bash
$ printf "0\n1\n4\n9\n" | ./slope
1
3
5
```

### 刻み幅を指定する場合（`-d` オプション）

刻み幅には正の数を指定します。指定しない場合は 1 として計算されます。

```bash
$ printf "0\n1\n4\n" | ./slope -d 0.5
2.0
6.0
```

### パイプでつなぐ例

```bash
$ printf "0\n1\n4\n9\n16\n" | ./slope | ./slope
2
2
2
```

### エラー時の動作

数値以外の文字列、2個未満のデータ、0 以下の刻み幅が与えられた場合は、標準エラー出力へメッセージを出し、終了コード 1 で終了します。
