# slope

![test](https://github.com/kuroiwarikuto/slope/actions/workflows/test.yml/badge.svg)

標準入力で渡した数値列の変化率（傾き）を計算して出力するコマンドです。
## 機能

- 1行ごとに数値（整数・小数）を読み込み、前の値との差を順番に出力します。
- `-d`（`--delta`）オプションで刻み幅を指定すると、差を刻み幅で割った変化率を計算します。
- パイプで2回つなぐと、2階差分も計算できます。

## インストール方法

```bash
$ git clone https://github.com/kuroiwarikuto/slope.git
$ cd slope
```

## 使い方

### 基本的な実行例

改行で区切った数値を標準入力から渡します。

```bash
$ printf "0\n1\n4\n9\n" | ./slope
1
3
5
```

### 刻み幅を指定する場合（`-d` オプション）

刻み幅には正の数を指定します。指定しないときは1として計算します。

```bash
$ printf "0\n1\n4\n" | ./slope -d 0.5
2.0
6.0
```

### パイプでつなぐ例

```bash
$ printf "0\n1\n4\n9\n16\n" | ./slope | ./slope
2
2
2
```

### エラー時の動作

数字以外が入力されたときや、データが1個以下のとき、刻み幅に0以下を指定したときは、標準エラー出力にメッセージを出して終了コード1で終了します。
